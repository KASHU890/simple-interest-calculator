# Contributing

Thank you for your interest in contributing to the Simple Interest Calculator project!

## Contributions

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear message.
5. Push your branch to your GitHub repository.
6. Open a pull request describing your changes.

## Bug Reports

If you find a bug, please create an issue and provide:

* A clear description of the problem.
* Steps to reproduce the issue.
* Expected behavior.
* Actual behavior.

## Documentation Improvements

Documentation improvements are welcome. Please make sure that any new documentation is clear, accurate, and easy to understand.

## Enhancements and Ideas

Suggestions for new features, improvements, and ideas are encouraged. Please describe the proposed enhancement clearly when submitting an issue or pull request.

## Code of Conduct

Please follow the project's `CODE_OF_CONDUCT.md` when participating in the project.

Thank you for contributing!
